# Object and vegetation tracing skill — 1 October 2026

The existing `$addr-roof-tracing` skill now describes the visible boundary target for all 13 supported scene classes, with dedicated guidance for trees, hedges, bushes/shrubs and ground or mixed vegetation. It distinguishes outer-boundary correction, logical grouping, visible foliage patches, biological instance hypotheses and user-requested allocation sections.

Tree review follows visible foliage and keeps shadow, crop cuts, touching crowns and internal shaded texture separate. Hedge review follows continuous planted strips, supported ends and actual breaks. Bush review follows foliage clumps rather than the soil/bed perimeter. Descriptive subtype labels do not certify species, stems or measured height.

Finer segmentation uses `preview_object_split`, `inspect_object_split` and `apply_object_split`. A preview contains two to eight keyed children, optional labels/notes and an explicit `unresolved-residual` role. Every child is the same source class. The inspected parts must cover the source exactly, retain holes and avoid overlap; the registered original/grid/parts images and child inspections expose exterior edges and every new seam.

The canonical save retains the source as superseded and all children as unchecked machine drafts with reciprocal replacement lineage. Group membership is inherited unless a new shared flat group label is explicitly supplied. Split children can be inspected and refined with generic polygon tools, or split again. Physical support links stay physical; they do not become a taxonomy of tree subparts. Active attached objects require a separate parenting decision and block this automatic split path.

The app currently has flat groups with one membership per object. There is no arbitrary nested group schema. A pure split also cannot remove an erroneous connector across an open gate/path: that can require a disconnected, coverage-changing replacement. The skill records that limit and retains a proposal or explicit residual rather than pretending a successful cut repaired the mask.

Nine retained source-bound vegetation examples cover crop-induced hedge shapes, a roof-edge vegetation false positive, fragmented clumps, ambiguous crown contacts and dark foliage holes. No defensible biological split seam was found in that set, so no real scene was partitioned. An independent forward test inspected all 33 edges/corners and possible seams of tree0 and retained one visible crown patch. These are machine observations, not approved labels.

Validation passed: 167 focused Python tests, TypeScript lifecycle and polygon guards, typecheck, and `task lint` (zero errors, 29 existing ESLint warnings). An independent review exercised 28 isolated protection/geometry/lineage scenarios. Seventeen official MCP SDK helper calls against the canonical local API demonstrated split → child inspection → polygon refinement → further split on a disposable fixture. Its rectangular test parts are transport/lifecycle evidence, not biological vegetation segmentation; the fixture and server previews were removed. All nine original model/PNG pairs and the protected-reference/frozen-run checks remained unchanged.
