Existing palette navy #090f1c, panels #111b2b, raised #1b293d, border #2a3b51, text #edf3f8, muted #a0b1c5, cyan #67d7e7. Green ridges, cyan hips, lilac valleys are DATA encodings only.
Composition: One coherent desktop screen. Thin top navigation with back to Map, Scene review title, address, saved revision 6, quiet Training coverage link. Main area uses almost all height: clear heading Main roof, small needs edit indicator; tabs Review / Roof lines / 3D apexes; above image a small toolbar Move, Draw, line type, undo redo. Dominant central aerial-image canvas with a simplified long L-like roof shown as an ILLUSTRATIVE sample. Legible fine green/cyan/lilac lines and circular editable junctions; quiet boundary dotted white; compact bottom legend. Right inspector 260px: heading Roof lines; 15 lines; selectable rows Ridge/apex, Hip, Valley with counts, selected line type and length, concise Add junction / Delete actions; visibility toggles for Your edits, Starting estimate, Boundary; notes input and imagery checked checkbox. Bottom aligned save strip showing Saved revision 6 and primary Save roof line feedback button. Fit image, enhanced imagery and context controls small and grouped.
